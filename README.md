# Customer Spending Behavior Segmentation Using Clustering

## 📌 Project Overview

This project uses Unsupervised Machine Learning to group customers based on their spending and purchasing behavior.

The project applies two clustering techniques:
- K-Means Clustering
- DBSCAN Clustering

The aim is to discover different customer spending patterns without predefined labels.

## 💼 Business Problem

A company may have many customers, but not all customers spend money in the same way.

Some customers spend more, some spend less, and customers may differ in their purchase frequency, online spending, offline spending, savings, and discount usage.

This project groups customers with similar spending behaviors into meaningful segments.

These segments can help businesses understand customer behavior and support:
- Targeted marketing
- Personalized offers
- Customer engagement
- Discount strategies
- Customer behavior analysis

## 🤖 Machine Learning Techniques

### K-Means Clustering

K-Means groups customers into clusters based on similarities in their spending behavior.

### DBSCAN

DBSCAN identifies dense groups of customers and can also identify unusual or isolated observations.
